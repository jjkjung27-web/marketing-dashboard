# Image Variation Tool — Design Spec
Date: 2026-05-19

## Overview

팀원들이 공유해서 사용하는 웹 기반 광고 소재 배리에이션 툴.
원본 이미지 시안을 업로드하면 Claude Vision이 레이아웃을 분석하고, PIL로 다양한 매체 사이즈에 맞게 재구성해준다.
선택적으로 Figma/이미지/PDF 가이드 파일을 추가하면 브랜드 규칙을 반영한 배리에이션을 생성한다.

## Goals

- 원본 이미지 1장 → 매체별 다양한 사이즈 배리에이션 자동 생성
- 광고 소재 + SNS 콘텐츠 양쪽 용도 지원
- 팀원 확인(Human-in-the-loop) → 최종 생성 워크플로우
- Streamlit Cloud로 URL 공유, 별도 설치 없이 팀 사용

## Non-Goals

- Figma API 직접 연동 (v2에서)
- DALL-E 등 외부 이미지 생성 API 사용
- 완전 자동 생성 (사람 확인 단계 필수)

## Architecture

```
image_variation_tool/
├── app.py                  # Streamlit 메인 앱
├── core/
│   ├── analyzer.py         # Claude Vision으로 이미지 분석
│   ├── layout_engine.py    # PIL로 배리에이션 생성
│   └── guide_parser.py     # PDF/이미지 가이드 파싱
├── presets/
│   └── sizes.json          # 매체별 사이즈 프리셋
└── requirements.txt
```

## User Flow

```
1. 원본 이미지 업로드 (PNG/JPG)
2. 가이드 파일 업로드 (선택 — PNG/JPG/PDF)
3. 목표 사이즈 선택 (프리셋 or 직접 입력)
4. Claude Vision이 원본 + 가이드 분석 → 레이아웃 제안
5. 팀원이 분석 결과 확인, 제외할 사이즈 선택
6. "생성" 클릭 → PIL이 각 사이즈별 이미지 생성
7. 다운로드 형식 선택 (PNG / JPG / SVG) → ZIP으로 일괄 다운로드
```

## Claude Vision Analysis

원본 이미지에서 추출하는 정보:
- 주요 요소 위치: 로고, 메인 카피, 서브 카피, CTA 버튼, 히어로 이미지
- 여백 비율 (상/하/좌/우)
- 색상 팔레트 (주색/보조색/배경색)
- 폰트 스타일 추정 (크기, 굵기, 색상)

가이드 파일이 있을 때 추가로 추출:
- 로고 안전 영역 및 최소 크기
- 사용 가능한 색상 팔레트
- 텍스트 배치 금지 영역
- 여백 규칙

## Layout Engine (PIL)

- 추출된 요소를 목표 사이즈 비율에 맞게 재배치
- 텍스트 크기 자동 조정 (사이즈 비율 기반)
- Safe Zone 자동 적용 (전체의 5% 여백)
- 가로형 ↔ 세로형 전환 시 요소 배치 우선순위: 로고 > 메인 카피 > 히어로 이미지 > 서브 카피 > CTA

## Guide File Parsing

| 형식 | 처리 방식 |
|------|-----------|
| PNG/JPG | Claude Vision으로 직접 분석 |
| PDF | 페이지별 이미지 변환 후 Claude Vision 분석 |
| Figma | Figma에서 Export한 PNG/PDF 사용 (API 연동은 v2) |

## Tech Stack

| 항목 | 기술 |
|------|------|
| 프레임워크 | Streamlit |
| AI 분석 | Claude Vision (claude-sonnet-4-6) |
| 이미지 처리 | Pillow (PIL) |
| PDF 처리 | pdf2image + poppler |
| 배포 | Streamlit Cloud |
| 언어 | Python 3.11+ |

## Export Options

| 형식 | 설명 |
|------|------|
| PNG | 투명 배경 지원, 고화질 |
| JPG | 파일 크기 작음, 배경 있는 소재에 적합 |
| SVG | Figma import 가능, 벡터 기반 |

- 생성 완료 후 형식 선택 → 선택한 형식으로 전체 ZIP 다운로드
- 사이즈별 개별 다운로드도 지원

## Human-in-the-Loop

- Claude 분석 결과를 팀원이 확인하는 단계 필수
- 확인 화면에서 제공하는 것:
  - 분석된 요소 목록 (수정 가능)
  - 각 사이즈별 미리보기 썸네일
  - "이 사이즈는 제외" 체크박스
- 확인 후 "생성" 버튼 클릭 시 최종 이미지 생성

## Out of Scope (v1)

- 사용자 계정/로그인
- 생성 이력 저장
- Figma API 직접 연동
- 외부 이미지 생성 AI (DALL-E 등)
- 텍스트 편집 기능 (레이아웃 재배치만)
