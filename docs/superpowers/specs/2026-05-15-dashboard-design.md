# 마케팅 대시보드 설계 (2026-05-15)

## 요약
퍼마 팀 일일 모니터링용 Streamlit 대시보드. 매일 아침 탭1만 열어도 이상치·예산·전환 상황을 한눈에 파악할 수 있도록 설계.

## 3탭 구조

### 탭1: 📊 오늘 현황
- 이상치 알림 배너 (빨강/노랑)
- KPI 카드 2행 — 전일 대비 delta(▲▼) + 이상치 테두리
  - 행1: 총비용, 노출, 클릭, CTR, CPC
  - 행2: 구매, 구매매출, CPA, ROAS
- 채널별 요약 테이블 — 비용/ROAS/CPA/전일대비/신호등

### 탭2: 📡 채널 분석
- 채널 선택 → 일별 추이 차트 (비용 / 노출+클릭 / CTR+CPC)
- 캠페인 드릴다운 테이블 (채널→캠페인→그룹)

### 탭3: 🎨 소재 분석
- 섹션1: 포맷별 성과 — VID/IMG/CRS/TXT 막대 차트 (CTR, CPA, ROAS)
- 섹션2: A/B 테스트 결과 — A변형 vs B변형 나란히, 승자(🏆) 자동 표시

## 이상치 기준 (사이드바 설정)
- 전일 대비 CPA 변화율 임계값 (기본 +30%)
- 전일 대비 ROAS 변화율 임계값 (기본 -20%)
- 목표 CPA / 목표 ROAS (선택 입력, 입력 시 목표 대비도 병행 표시)
